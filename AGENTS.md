# Agent instructions

Read docs/HANDOFF.md before making changes.

This repository supports the offline Liberty basemap work.

- Do not modify the production geology-map repository.
- Keep experiments minimal and reproducible.
- Preserve existing data, licenses, provenance and checksums.
- Do not assume the missing probe assets are present.
- Do not treat Dart HTTP success as proof of native glyph loading.
- Use live emulator screenshots, not map.takeSnapshot(), for rendering tests.
- Do not commit, push, merge or delete data without explicit approval.
